IPHONE QUICK STEPS
1. Tap the ZIP link in ChatGPT and choose Download.
2. Open the Files app > Downloads. Tap the ZIP once to extract it.
3. Open the extracted folder and find index.html.
4. For GitHub: open github.com in Safari, open your repository, tap Add file > Upload files. Select index.html from Files and commit.
5. In repository Settings > Pages, choose Deploy from a branch, branch main, folder /(root), then Save.
6. Wait a minute or two. Your site URL will be https://YOUR-USERNAME.github.io/REPOSITORY-NAME/
